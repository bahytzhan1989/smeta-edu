# Правила работы над приложением

- Работай только в этой папке. Перед изменениями сначала прочитай текущие файлы.
- Делай только ту функцию, которую попросил пользователь, и не ломай уже работающие возможности.
- Используй только обычные HTML, CSS и JavaScript. Не добавляй npm, фреймворки или внешние ресурсы.
- Данные пользователя должны оставаться в браузере. Ничего не отправляй в интернет.
- Делай интерфейс удобным: используй понятные подписи; высота полей и кнопок — не меньше 44 px; обеспечь работу с клавиатуры и на телефоне.
- Показывай деньги с пробелами между тысячами, например `15 000 ₸`. Пустые и неверные числа считай нулём; никогда не показывай `NaN`.
- Не запускай git и ничего не публикуй без просьбы пользователя.
- После работы перечисли изменённые файлы и объясни, как проверить результат.
