# Смета за 5 минут

«Смета за 5 минут» — простое веб-приложение, чтобы быстро составить смету или коммерческое предложение и сохранить его в PDF. Оно предназначено для предпринимателей, готовящих КП клиентам, и офисных сотрудников, которым нужно оформить смету закупки или расходы для руководителя.

## Файлы приложения

- `index.html` — структура страницы, поля для ввода и кнопки.
- `styles.css` — внешний вид и адаптация интерфейса для телефона.
- `script.js` — расчёты, обработка действий пользователя и подготовка документа к сохранению в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html` — приложение откроется в браузере.

## Как проверить расчёт

Добавьте две позиции: 2 × 15 000 ₸ и 1 × 8 000 ₸. Общая сумма должна быть **38 000 ₸**.
